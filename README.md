AI-powered Data Analytics Copilot built with Streamlit, Gemini API, RAG architecture, FAISS vector database, and automated EDA visualizations.

---

## 🚀 Features

- Chat with CSV data
- Gemini AI integration
- RAG memory system
- Automated charts & analytics
- Streamlit dashboard
- FAISS vector search
- Clean SaaS architecture
- Interactive AI-powered insights
- Upload and analyze datasets instantly

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- LangChain
- FAISS
- Pandas
- Plotly
- Matplotlib
